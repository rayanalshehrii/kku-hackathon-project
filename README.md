# Saudi Vision 2030 Landing Page

## What it does

Presents a polished, responsive introduction to Saudi Vision 2030 through its three themes, selected goals, transformative projects, and global outlook. The page includes an accessible light/dark mode toggle that remembers the selected theme.

## Who it is for

Anyone who wants a concise visual overview of the Vision 2030 direction, including visitors, students, and hackathon reviewers.

## Needs

A modern web browser. No installation, account, internet connection, server, or external dependency is required.

## How to run it

Double-click `index.html` to open the page in a browser. All styles, artwork, and scripts are stored locally, so the page also works offline.

## Try it with the sample data

This page does not collect or store visitor data. It contains presentation content only, so no sample-data file is needed at runtime.

## Accessibility and theme

- Use the visible header button to switch between light and dark themes.
- The chosen theme is saved in the browser and restored after refresh.
- When no theme has been chosen, the page follows the device color preference.
- Keyboard users can use the skip link, visible focus states, and standard navigation keys.

## Source note

No Vision 2030 PDF files or visual reference assets were provided in this project folder. The page uses the themes, initiatives, and target values specified in the project request and avoids additional unsupported statistics or claims.
